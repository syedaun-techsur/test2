<task type="auto">
  <name>Create Express server with CRUD endpoints</name>
  <files>server/index.js</files>
  <action>
Create Express server at server/index.js with:

1. Setup: express.json(), cors, port 3001
2. GET /api/tasks - Returns all tasks from tasks.json
3. POST /api/tasks - Creates new task with UUID v4, validates text (1-500 chars, not empty/whitespace-only), returns 201
4. PATCH /api/tasks/:id - Updates task completion status, validates task exists, returns 200
5. DELETE /api/tasks/:id - Deletes task by ID, validates exists, returns 200
6. Error handling: 400 for validation errors, 404 for not found, 500 for server errors

Task schema: { id: string, text: string, completed: boolean, createdAt: ISO string, updatedAt: ISO string }

All responses follow FRD format: { success: true, data: ... } or { success: false, error: { code, message } }
  </action>

pkill -f "node server/index.js"</verify>
  <done>All four endpoints work: GET returns tasks, POST creates task, PATCH updates completion, DELETE removes task</done>
</task>
