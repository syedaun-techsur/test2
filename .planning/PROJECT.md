# Todo App

## What This Is

A simple todo app with a React frontend and a Node/Express backend. Users can create tasks, mark them complete, and delete tasks. Clean, minimal task management for personal productivity.

## Core Value

A simple, fast way to manage daily tasks with create, complete, and delete functionality.
